# UMS
Unity Music Script

1.박자표를 만들어야함. 박자가 재생하고있는 음원하고 일치하게 만듬
BPM->1 비트당 몇초로 환산
라인의 갯수를 설정(기본 4개)

2.노트
노트의 종류(one hit/long hit), 노트의 위치를 좌표로 저장(one hit는 끝좌표가 자동으로 한박자 뒤로 설정). 노트의 크기를 설정(기본 1)
노트에 할당된 점수는 tag로 설정.

3.저장
BPM,자켓,곡 파일,라인 수
이름,아티스트, 곡 길이( 가장 큰 좌표에서 유예기간 1초정도 혹은 설정 )
노트들

4.리드
파일을 읽은 뒤 비동기 읽기를 함.
(화면상 표시를 해주는 스크립트를 받아야함.
판정선 위치(오브젝트를 받고 위치)
판정 시스템(버퍼)
노트 프리팹에 들어갈 이미지들
효과들


배치 명령이 끝나면 시작 할지말지 결정
